📚 Beginner Lessons

1. Cyber Security क्या है?

Cyber Security का उद्देश्य computers, networks, accounts और data को unauthorized access और cyber threats से सुरक्षित रखना है।

2. Strong Password

अलग-अलग accounts के लिए अलग password रखना, लंबा password इस्तेमाल करना और MFA/2FA enable करना account security को बेहतर बनाता है।

3. Phishing क्या है?

Phishing में attacker fake message या website के जरिए sensitive information लेने की कोशिश कर सकता है। Unknown links और suspicious requests से सावधान रहें।
